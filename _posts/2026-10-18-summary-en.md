Global solar power generation has officially overtaken nuclear energy output for the first time, driven by a 27% year-on-year increase in solar capacity to 2,383 GW. Between March 2025 and June 2026, solar and wind energy individually outperformed nuclear generation in multiple months. This milestone marks a significant paradigm shift in the global energy landscape, demonstrating the rapid scalability and economic viability of renewable energy compared to traditional baseload power sources like nuclear. ## [EpochGo: Local-first multi-agent AutoML engine using Ollama and Scikit-Learn](https://www.reddit.com/r/MachineLearning/comments/1x8c2sq/epochgo_localfirst_multiagent_automl_engine_using/) ⭐️ 8.0/10

EpochGo is an open-source AutoML framework that uses local LLMs via Ollama for orchestration while delegating all data processing and modeling to deterministic Scikit-Learn pipelines. It runs entirely offline on consumer hardware to eliminate cloud costs and data privacy risks. This architecture solves the 'hallucination' problem in LLM-driven ML by separating reasoning from execution, ensuring that mathematical operations remain accurate and deterministic. It provides a compliant, cost-effective solution for enterprises handling sensitive tabular data. The system uses Qwen2.5-coder:7b to analyze schema metadata without accessing raw data rows, and validates generated code via Abstract Syntax Trees (AST) to ensure security. It supports automated model selection and generates containerized FastAPI endpoints for deployment.

Traditional agentic AI frameworks often rely on cloud-based LLMs, which can introduce privacy concerns and high costs when processing proprietary enterprise data.

## [OpenCode Breach Exposes OpenAI, Anthropic, and Google API Keys](https://startupfortune.com/opencode-breach-exposes-stored-openai-and-anthropic-keys-prompts-urgent-key-rotation/) ⭐️ 8.0/10

OpenCode confirmed that a large-scale distillation attack resulted in the exposure of stored API keys for approximately 1.4% of its Console users. The company has notified affected users and is working with OpenAI, Anthropic, and Google to address the security incident. This breach highlights the significant risks associated with storing third-party API credentials in centralized platforms. It serves as a critical reminder for developers to practice regular key rotation and implement strict spending limits on their AI service accounts. The company advises affected users to immediately revoke and regenerate their keys, review account usage logs since October 17, and set spending caps to prevent unauthorized charges. While the company is investigating, it has not yet confirmed whether the exposed keys were maliciously exploited.

telegram · zaihuapd · Oct 17, 23:43

**Background**: A model distillation attack involves an attacker repeatedly querying a proprietary AI model through its API to extract its capabilities and train a cheaper 'student' model. API key rotation is a standard security practice that involves periodically invalidating old keys and issuing new ones to minimize the window of opportunity for attackers if a key is compromised.

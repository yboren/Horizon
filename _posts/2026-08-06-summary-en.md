## [Celld: A Self-Hosted, Distributed Durable Objects Implementation](https://github.com/denoland/celld) ⭐️ 8.0/10

Celld is a new open-source system that implements the Durable Objects pattern by utilizing SQLite for state management and S3-compatible storage for persistence. It allows developers to run stateful, distributed applications outside of proprietary cloud environments. This project provides a critical open-source alternative to vendor-locked services like Cloudflare's Durable Objects, enabling greater portability and control over distributed state. It addresses a significant demand for self-hosted infrastructure that maintains the simplicity and power of the Durable Objects abstraction. Each object in Celld functions as its own SQLite database, which is addressed by name and replicated to an S3-compatible bucket. The project maintains a strict contribution policy, requiring patches to be submitted via git format-patch rather than standard pull requests.

hackernews · calvinfo · Aug 5, 16:50 · [Discussion](https://news.ycombinator.com/item?id=49185430)

**Background**: Durable Objects are a pattern for building stateful applications at the edge, where each object maintains its own persistent state and handles requests sequentially. This architecture simplifies distributed systems by providing strong consistency for individual objects, which is traditionally difficult to manage across multiple nodes.

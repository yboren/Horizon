OpenAI has announced a potential proof for the Navier–Stokes existence and smoothness problem using an unreleased internal model. It also raises critical questions regarding research ethics, authorship, and the competitive dynamics between major AI laboratories. Solving it is considered essential for understanding turbulence, a complex phenomenon in physics and engineering.

## [I-have-ADHD: A prompt technique to stop coding agents from being verbose](https://github.com/ayghri/i-have-adhd) ⭐️ 8.0/10

I-have-ADHD is a specialized system prompt designed to force coding agents to provide concise, direct answers by suppressing their tendency to explain what they did not do. It specifically targets the 'Claudism' behavior where models provide excessive, unnecessary commentary alongside code changes. This tool addresses a significant pain point for developers who find AI coding assistants increasingly verbose and difficult to manage. By enforcing brevity, it improves the efficiency of AI-assisted coding workflows and reduces the cognitive load of parsing agent responses. The project provides a plugin-like system prompt that users can integrate into their CLI or agentic workflows. Users have noted that while effective, models may eventually revert to verbose habits, requiring consistent reinforcement or re-application of the prompt.

## [Running Kimi K3 2.8T Model on MacBook Pro via SSD Weight Streaming](https://github.com/argonautlabsai/deltafin) ⭐️ 8.0/10

Argonautlabs has demonstrated the ability to run the massive 2.8 trillion parameter Kimi K3 model on a MacBook Pro by streaming weights from a four-SSD array. This setup achieves an inference speed of approximately 1 token per second. This achievement highlights the potential for running frontier-scale models on consumer hardware by bypassing traditional RAM limitations. It pushes the boundaries of systems engineering, demonstrating how disk-based inference can make massive models accessible outside of enterprise data centers. The system utilizes a four-SSD array to overcome bandwidth bottlenecks, though the performance is heavily constrained by the read speeds of the storage medium. While technically impressive, the inference speed remains extremely slow for practical, real-time interactive applications.

hackernews · Argonautlabs · Sep 8, 20:07 · [Discussion](https://news.ycombinator.com/item?id=49616257)

**Background**: Kimi K3 is a 2.8 trillion parameter Mixture-of-Experts (MoE) model developed by Moonshot AI, featuring a 1-million-token context window. Traditional LLM inference requires loading the entire model into VRAM or RAM, which is impossible for models of this size on consumer hardware. Weight streaming is an emerging technique that loads only the necessary model layers from disk into memory on-the-fly during the forward pass.

This project leverages a WebSocket-based protocol called Wisp to handle network traffic, as browsers cannot natively open arbitrary network connections. It highlights the potential for running entire operating systems or desktop applications directly within a web browser. The project specifically targeted Firefox's Gecko engine due to its strong single-process support and utilized AI-assisted programming tools for the porting effort. It supports end-to-end encryption for traffic, ensuring that requests to HTTPS sites remain secure while being proxied through the server.

Wisp is a wire protocol designed to facilitate network communication in environments where standard socket access is restricted.
